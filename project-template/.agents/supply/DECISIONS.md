# Accepted decisions and known limits

Things the user decided to **leave as they are**, and limits that are known and deliberate. Unlike `MEMORY.md` (800 words) and `NOTEBOOK.md` (50 lines), this file has **no line cap and is never pruned by age**: an entry is removed only when the user reverses the decision or the code changes (say so in the session).

**Before "fixing" something that looks like a gap, search this file.** If it is listed here, do not change it without asking the user first.

Add an entry when the user says "leave it", "for now let's keep it", or accepts a known limit. Format: date, area, the decision, why, how to apply. Newest first.
